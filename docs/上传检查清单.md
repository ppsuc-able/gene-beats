# GitHub 提交检查清单

## 应上传

- `README.md`
- `package.json`
- `.gitignore`
- `dist/`：网页、样式、交互和核心算法
- `data/`：示例 FASTA 序列
- `docs/`：项目报告、答辩提纲和上传说明
- `tests/`：算法测试
- `scripts/`：本地预览脚本

## 不必上传

- `作业_UML/`：与本项目无关的其他作业
- `artifacts/`：本地压缩包和临时交付物
- `.git/`：Git 的本地历史目录
- `node_modules/`、临时截图、缓存、个人账号信息

## 老师检查顺序

1. 阅读根目录 `README.md`。
2. 打开 `dist/index.html`，体验 DNA 翻译、ORF 雷达、突变盲盒、序列身份证和进化模拟。
3. 查看 `docs/项目报告.md` 和 `docs/答辩提纲.md`。
4. 在项目根目录运行 `npm test`，确认算法测试通过。

## 网页上传时

在仓库页面选择 **Add file → Upload files**，把本清单中“应上传”的文件和文件夹拖入页面，保持文件夹层级不变，然后提交。

## Git 上传时

在项目根目录执行：

```bash
git add README.md package.json .gitignore dist data docs tests scripts
git commit -m "Add Gene Beats bioinformatics project"
git remote add origin https://github.com/ppsuc-able/-.git
git push -u origin HEAD
```

如果提示没有权限，说明当前 GitHub 登录账号不是 `ppsuc-able`，或者该账号还没有这个仓库的写入权限。
