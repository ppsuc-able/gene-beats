# Gene Beats：DNA 序列翻译与突变结果的交互式声化

## 项目目标

通过输入 DNA、计算序列特征、执行密码子翻译并比较突变前后结果，让使用者理解遗传密码简并性、错义突变与无义突变。将氨基酸映射到音符，增加课堂参与度。该项目属于教学工具，不开展临床或功能预测。

## 数据与方法

数据使用 `data/demo.fasta` 中的人工教学序列，长 60 bp。样本刻意设计为可产生同义、错义和无义突变，不能代表真实基因分布或生物学效应。

翻译规则依据 [NCBI 标准遗传密码表 1](https://www.ncbi.nlm.nih.gov/Taxonomy/Utils/wprintgc.cgi?chapter=tgencodes#SG1)。输入只保留空白清除后的 A/C/G/T；FASTA 只接受单条记录。模糊碱基、RNA 字母及数字明确报错。

处理流程：输入校验 → 碱基计数 → GC 计算 → 按阅读框分组 → 密码表查询 → 首个终止处结束 → 突变结果比较 → 音高映射和展示。扩展流程对输入生成反向互补序列，扫描正负链各三个阅读框，记录 ATG 到首个同框终止密码子的完整 ORF，并把负链坐标换算回原始输入坐标。

GC% = 100 × (G 的数量 + C 的数量) / 输入长度。阅读框偏移为 0、1 或 2，随后每隔 3 位提取一个密码子；不进行起始密码子识别。统计以全部输入碱基为范围，翻译只覆盖所选阅读框至首个终止密码子。

音高方案：氨基酸按 `ACDEFGHIKLMNPQRSTVWY` 排列，索引 i 的 MIDI 音高为 `48 + 12 × floor(i/5) + [0,2,4,7,9][i mod 5]`。频率采用 `440 × 2^((MIDI−69)/12)` Hz。终止密码子不发声；不同氨基酸对应不同音高，不将功能性质编码为声音。

## 实验设计与结果

固定 +1 阅读框、相同速度、相同音色，以原始序列为对照，每次只改变一个碱基。完整原始氨基酸输出为 `MAEFGWKPYDQVSTRNCHL`。

| 条件 | 结果 | 可观察变化 |
| --- | --- | --- |
| 原始序列 | 19 aa | 对照旋律 |
| 第 6 位 T→C | 同义，19 aa | 密码子改变，氨基酸和音高不变 |
| 第 8 位 A→C | 错义，19 aa | 第 3 个氨基酸 E→A |
| 第 17 位 G→A | 无义，5 aa | 在第 6 个密码子终止 |

核心算法通过 Node 内置测试器验证，测试源文件为 `tests/bio.test.js`，运行 `npm test` 可复现十组测试。测试包括输入拒绝、GC、阅读框、提前终止、单碱基增删、三种预设、终止丢失、音高唯一性、反向互补、ORF 坐标、盲盒候选、DNA 指纹和进化模拟。此验证不等于浏览器音频实测，也不验证生物学功能。

新增“突变盲盒”在当前翻译区前 120 个密码子内枚举所有单碱基替换，通过标准密码表直接归类为同义、错义或无义突变。用户作答前只看到位置和碱基变化，作答后才显示密码子与氨基酸结果，并更新对照图谱。该设计避免把答案写死在界面中，也便于课堂重复实验。

“序列身份证”统计 16 种二联体的频数，用归一化 Shannon 熵计算复杂度，并用稳定哈希生成 8 位指纹。它使同一输入的实验结果容易核对，但不承担分类、鉴定或亲缘推断。“进化模拟”以指纹和阅读框作为随机种子，在已翻译区每代替换一个碱基，计算与原始蛋白质的身份保持率。相同输入和代数会得到相同轨迹，便于课堂复现。

## 实现与复杂度

使用 HTML、CSS、JavaScript 和 Web Audio API，无第三方运行时依赖。计算模块与界面模块分离，既能在浏览器使用，也能通过 Node 测试。分析时间 O(n)，空间 O(n)；前端图谱与播放限制为前 120 个密码子，JSON 导出保留完整分析。

## 局限与后续工作

只接受明确的 DNA 字母；仅标准密码表；不处理剪接、非 ATG 起始、部分 ORF 或真实注释；预设不是数据库样本；声音为人为映射；不能把旋律变化解释为功能变化幅度。ORF 雷达给出候选片段，不证明它是真实基因。后续可增加来源明确的公共 CDS、注释对照和批量分析，但需要独立设计与验证。
