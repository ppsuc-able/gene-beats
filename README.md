# Gene Beats · DNA 音乐实验室

一个把 DNA 序列分析与音乐交互结合的生物信息学期末项目。输入 DNA，查看 GC 含量和翻译结果，制造一次突变，再比较变化前后的氨基酸旋律。

**课堂问题：改一个碱基，旋律一定会变吗？** 用同义、错义、无义突变三个实验，让同学先预测，再验证。

## 立即运行

下载整个项目，双击 `dist/index.html`，用 Chrome 或 Edge 打开。无需安装依赖、无需联网；点击播放才会发声。请保留 `dist` 内四个文件的相对位置。

也可以使用 Node.js 18 或更新版本：

```sh
npm start
```

打开终端显示的本地地址。验证算法：

```sh
npm test
```

## 功能

- 解析单条 FASTA 或纯 DNA，校验输入；最多 6,000 bp。
- 计算碱基组成、GC 含量，选择正向 +1 / +2 / +3 阅读框。
- 使用 NCBI 标准遗传密码表 1 翻译，遇到首个终止密码子停止。
- 模拟单碱基替换、插入、删除；比较密码子及氨基酸输出。
- 同时扫描正链与反向互补链的六个阅读框，定位 ATG 到同框终止密码子的完整 ORF。
- 生成稳定的 DNA“身份证”：用 16 种二联体频率计算序列指纹、复杂度和优势片段。
- 将 20 种氨基酸映射到 20 个不同音高，播放时同步高亮。
- 提供三个预设突变实验和随机“突变盲盒”：先判断同义、错义或无义，再揭晓结果并累计连胜分数。
- 用固定随机种子模拟 3–20 代碱基替换，观察蛋白质身份保持率的变化。
- JSON 导出包含原始分析、六阅读框 ORF、突变结果和挑战得分。

## 可复现的实验

内置序列是**人工设计的教学序列**，不是数据库下载的真实基因，包含 60 bp、19 个氨基酸和一个终止密码子。使用 +1 阅读框，从第 1 位开始计数。

```text
ATG GCT GAA TTT GGT TGG AAG CCT TAC GAT CAA GTT TCT ACT CGT AAT TGC CAT CTG TAA
 M   A   E   F   G   W   K   P   Y   D   Q   V   S   T   R   N   C   H   L   *
```

| 实验 | 单碱基操作 | 密码子变化 | 预期结果 |
| --- | --- | --- | --- |
| 同义 | 第 6 位 T → C | GCT → GCC | 都编码 A，19 个氨基酸及旋律保持不变 |
| 错义 | 第 8 位 A → C | GAA → GCA | 第 3 个氨基酸 E → A，改变一个音符 |
| 无义 | 第 17 位 G → A | TGG → TAG | 第 6 个密码子成为终止，只输出前 5 个氨基酸 |

预设按钮会载入上述教学序列并切换到 +1 阅读框。自定义突变每次基于当前原始序列，不会在上一突变上叠加。

## 科学依据与限制

翻译表来自 [NCBI：The Genetic Codes，Table 1](https://www.ncbi.nlm.nih.gov/Taxonomy/Utils/wprintgc.cgi?chapter=tgencodes#SG1)，查阅日期为 2026-09-11。采用其 64 个密码子的标准对应关系；TAA、TAG、TGA 为终止密码子。

普通“分析序列”执行的是**所选正向阅读框的直接查表翻译**：输入视为 5′→3′ 编码链，不自动寻找起始密码子。ORF 雷达另行生成反向互补链，扫描六个阅读框，只报告以 ATG 开始并以 TAA、TAG 或 TGA 同框结束的完整 ORF。它不处理剪接位点、非 ATG 起始、部分 ORF 或重叠基因注释，也不模拟特殊起始密码子的翻译规则，不适用于线粒体等其他密码表。末尾不足三位不翻译。仅支持明确的 A/C/G/T，拒绝 N 和其他模糊符号。

序列身份证统计相邻碱基组成的 16 种二联体，使用归一化 Shannon 熵给出 0–100 的复杂度，并用稳定哈希生成 8 位指纹。它用于复现实验输入，不是物种鉴定或亲缘关系判断。进化模拟每一代在已翻译区随机替换一个碱基；随机种子由序列指纹和阅读框决定，因此同一个输入可复现同一条轨迹，但它不是自然选择、漂变或群体遗传学模型。

音高映射是人为的教学设计，不是 DNA 的天然声音，不能根据旋律推断蛋白质功能、致病性或进化关系。“同义突变”只表示本次氨基酸序列不变，并不证明其在真实细胞中没有影响。插入/删除的类别只描述当前操作和结果，不是完整的变异注释工具。

为控制演示时长，图谱、播放和盲盒出题最多使用前 120 个密码子；统计、ORF 扫描及导出保留完整分析。音高按照氨基酸单字母序列 `ACDEFGHIKLMNPQRSTVWY` 分配到从 MIDI 48 开始、跨四个八度的五声音阶。

## 项目结构

```text
dist/                 可离线打开、可部署的网页
  index.html          交互界面
  style.css           响应式样式
  bio.js              输入解析、翻译、突变分析、音高映射
  app.js              交互、音频播放、导出
data/                 人工示例 FASTA
tests/bio.test.js     核心算法回归测试
scripts/serve.js      无外部依赖的本地预览
docs/                 项目报告、答辩提纲、GitHub 上传说明
```

翻译、ORF 扫描、DNA 身份证和盲盒候选生成均为线性扫描，时间复杂度 O(n)，空间复杂度 O(n)。无第三方运行时依赖，不向服务器上传输入序列。
